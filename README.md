# Content Automation Bot

An AI-powered content bot that:
- Generates tweet drafts from topics using Google Gemini
- Checks content with a safety filter before showing it to me
- Sends drafts to Telegram for approval (Approve / Reject / Request Changes)
- Lets me give feedback and regenerate content via Gemini
- (Upcoming) Automates posting on a schedule

## Tech stack
- Python
- MySQL
- Google Gemini API
- Telegram Bot API
